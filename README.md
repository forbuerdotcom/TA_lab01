Лабораторная работа: базовые типы данных и конструкции Python

Учебный проект, в котором решены 11 практических заданий на закрепление базовых типов данных Python: числа, строки, списки, кортежи, множества и словари. Логика каждого файла инкапсулирована в функции, поэтому модули можно безопасно импортировать — код не выполняется автоматически при загрузке. Запуск любого задания доступен через консольное меню menu.py, функциональность покрыта автоматическими тестами на pytest.

Требования

    Python 3.8 или новее
    pytest 7.0 или новее (только для тестов)

Установка

Клонировать репозиторий и установить зависимости (рекомендуется виртуальное окружение):

python -m venv venvsource venv/bin/activate      # Linux/macOSvenv\Scripts\activate         # Windowspip install pytest

Запуск заданий

Главный способ — консольное меню. Оно выводит список всех заданий, запускает выбранное по номеру и завершает работу по команде 0:

python menu.py

Пример работы меню:
```
1. 00_distance
2. 01_circle
3. 02_operations
4. 03_favorite_movies
5. 04_my_family
6. 05_zoo
7. 06_songs_list
8. 07_secret
9. 08_garden
10. 09_shopping
11. 10_store
0. Выход
```
После выполнения задания программа ждёт нажатия Enter и возвращается в меню. Каждое задание можно запустить и по отдельности — файлы остаются самостоятельными скриптами:
``
python 00_distance.pypython 01_circle.py
``
В PyCharm меню запускается ещё проще: откройте menu.py и нажмите зелёный треугольник справа вверху (или правый клик по файлу -> Run 'menu'). В репозиторий уже добавлены run-конфигурации PyCharm для menu и 01_circle — их можно выбрать в выпадающем списке справа вверху и запустить той же кнопкой.
Запуск тестов

Тесты проверяют вычисленные значения каждого задания (расстояния между городами, площадь круга, суммарное время песен, расшифрованную фразу, множества цветов, итоги склада и т.д.), а также вывод main() каждого модуля. Всего в проекте 95 тестов.

Основной способ — pytest из корня проекта:

```
python -m pytest
# весь набор (95 тестов)python -m pytest -v
# подробный выводpython -m pytest tests/test_05.py       # тесты одного задания
```
Запускать тесты как обычные скрипты через кнопку Run в редакторе не обязательно, но можно: каждый тестовый файл сам добавляет корень проекта в sys.path и при прямом запуске вызывает pytest на своём файле:
```
python tests/test_00.py
```
Если модуль задания не находится при запуске тестов — убедитесь, что вы запускаете pytest из корня проекта и не перемещали тестовые файлы: каждый из них добавляет корень репозитория в sys.path по собственному расположению, именно поэтому импортируются модули с именами вида 00_distance.
Запуск тестов в PyCharm

Самый быстрый способ — встроенный терминал (Alt + F12), из корня проекта: python -m pytest запускает все 95 тестов одной командой.

Удобный способ — правый клик по папке tests в дереве проекта -> Run 'pytest in tests'. PyCharm сам определит pytest как тестовый раннер, покажет список всех тестов и зелёные кнопки запуска рядом с каждой тестовой функцией, а результаты прогона со статистикой появятся в отдельной панели. Если вместо этого запускать файл как обычный скрипт — ничего не сломается: сработает блок pytest.main([__file__]) в конце каждого тестового файла.

Перед первым запуском pytest должен быть установлен в выбранный интерпретатор: pip install pytest (или Settings -> Project -> Python Interpreter -> «+» -> pytest). Если PyCharm не распознаёт тесты, укажите раннер вручную: Settings -> Tools -> Python Integrated Tools -> Testing -> Default test runner -> pytest.
Как устроена инкапсуляция

В каждом файле задания вычисления оформлены отдельными функциями, которые возвращают результат (без вывода на экран), а печать вынесена в функцию main(). Вызов main() выполняется только при прямом запуске файла благодаря конструкции:
```
if __name__ == "__main__":    main()
```
Поэтому импорт модуля (или подключение через importlib.import_module('00_distance') в меню) не приводит к выполнению решения — модуль лишь предоставляет свои функции и данные.
